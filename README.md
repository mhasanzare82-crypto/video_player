# ویدیو پلیر

پخش‌کننده ساده ویدیوهای محلی گوشی، ساخته‌شده با Flutter.

## امکانات پیاده‌سازی‌شده در این شاخه
- انتخاب یک یا چند ویدیو از فایل‌گزین اندروید
- نمایش کتابخانه ویدیوها با تصویر بندانگشتی و نام فایل
- نگهداری فهرست انتخاب‌شده‌ها پس از بستن برنامه
- پخش ویدیو، توقف/ادامه، جلو و عقب رفتن ۱۰ ثانیه‌ای
- جابه‌جایی در نوار زمان و تنظیم بلندی صدا
- حالت تمام‌صفحه
- درخواست ورود به حالت تصویر در تصویر در Android 8.0 و بالاتر

## وضعیت قابلیت پس‌زمینه
پخش پایدار پس‌زمینه همراه با اعلان و دکمه‌های کنترل رسانه هنوز در این commit پیاده‌سازی نشده است؛ برای آن باید سرویس foreground رسانه‌ای و MediaSession اندروید اضافه و جداگانه روی دستگاه آزمایش شود. این قابلیت در این نسخه به‌عنوان تکمیل‌شده معرفی نمی‌شود.

## ساخت
GitHub Actions روی شاخه توسعه، APK آزمایشی را می‌سازد و به‌عنوان Artifact منتشر می‌کند.
